# GNU Automatic Picture Metadata generator (GNU APMG)

Ancien nom du projet : PhotoSémantique. Dépôt GitHub : [steveprudhomme/gnu-apmg](https://github.com/steveprudhomme/gnu-apmg).

Espace local de reprise du projet. Aucun code de la Phase 1 n'a encore été récupéré, développé ou testé ici.

Consulter [ROADMAP.md](ROADMAP.md) pour les vérifications effectuées, les prérequis manquants et les étapes à venir, puis le [tutoriel de reprise](docs/TUTORIEL.md).

Le dépôt public contient les documents de reprise. Aucune photo privée, donnée biométrique ou secret ne doit être ajouté au dépôt.
