# Étudier l’existant plutôt que le recopier

| Produit | Pratiques utiles | Limites et contrôle |
|---|---|---|
| digiKam | Tags hiérarchiques, écriture XMP/sidecar, géotags, interopérabilité | Ne pas recopier le code sans vérifier les licences |
| Immich | Navigation, recherche, regroupement de visages, UX | Ne pas imposer son serveur ni supposer sa base exportable |
| ExifTool | Lecture/écriture fiable des tags | Aucune écriture sur originaux en phases 1 et 2 |

L’interface pilote pourra se limiter à une CLI et à un rapport local. L’intégration XMP et la compatibilité digiKam seront testées sur des **copies synthétiques**, avec versions documentées.
