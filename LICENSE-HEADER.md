# Modèle d'en-tête de fichier source

Ce modèle est à adapter pour **chaque titulaire réel** ; n'inventez jamais une identité ni une adresse courriel publique. Le fichier `COPYING` contient la licence intégrale et fait autorité.

```python
# <Description en une ligne du rôle de ce fichier>
# Copyright (C) 2026 <Nom de l'auteur> <<adresse-courriel-publique-consentie>>
# SPDX-FileCopyrightText: 2026 <Nom de l'auteur> <<adresse-courriel-publique-consentie>>
# SPDX-License-Identifier: GPL-3.0-only
#
# Ce programme est un logiciel libre : vous pouvez le redistribuer et/ou le modifier
# selon les termes de la GNU General Public License version 3 telle que publiée
# par la Free Software Foundation.
# Ce programme est distribué sans AUCUNE GARANTIE ; voir COPYING.
```

Pour plusieurs contributeurs, conserver les notices existantes et ajouter les crédits pertinents. Ne jamais mettre de courriel privé sans permission. Les fichiers de tiers conservent leurs propres notices.
