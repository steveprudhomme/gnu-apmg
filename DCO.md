# Developer Certificate of Origin 1.1 — procédure

Avant de contribuer, consulter la version officielle du DCO 1.1 : https://developercertificate.org/ . Ajouter `Signed-off-by: Nom <courriel-public-consenti>` aux commits via `git commit -s` pour certifier les conditions indiquées par le DCO. Le maintien d'un copyright diversifié ne donne pas au mainteneur fondateur de permission unilatérale de relicenciation.
